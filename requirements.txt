# boto3/botocore/awscrt are pinned to exact versions, not ranges. aioboto3
# pins aiobotocore to an exact version, and aiobotocore pins botocore to a
# narrow range (see its own metadata). With loose bounds here, pip tries the
# newest boto3/botocore first, hits that narrow range, and backtracks one
# version at a time -- this is what makes "pip install -r requirements.txt"
# take a very long time on a fresh machine. Exact pins let pip resolve
# without searching.

botocore==1.40.61
